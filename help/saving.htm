Saving, Opening and Restarting

Description

Save the current position to a .mksol file and continue later. The original deal is saved too.

How to use

  1. Select Game > Save and choose a location and file name.
  2. Use Game > Open to select a saved game.
  3. Choose Game > Restart deal and confirm to replay the same original layout.

Note: A card-back preference belongs to the Windows user and is not changed by opening a game.

Tip: Choose Save as before experimenting if you want to retain an earlier position.

Warning: Saving again to the same file replaces its previous position. Restart changes the current position but does not restore an older saved checkpoint.

Limitations

Only valid MikasSolitaire .mksol files can be opened. Invalid or damaged files are rejected and do not replace the current game.

Example

Save as deal.mksol, close the app, and open that file to continue. Restart then returns to the deal's beginning.
