Release Notes

Description

This initial packaged release provides a playable single-draw Klondike game for Windows.

How to use

Install the application, start it from the Start menu, and open Help > Contents for instructions.

Note: Features include six card backs, saved games, undo, dragging, restarting the original deal and double-click foundation moves. The application and help are available in English and Finnish.

Tip: Keep a backup of important saved games before replacing a version of the application.

Warning: Uninstalling removes the installed application files. Keep saved games outside the installation directory.

Limitations

Scoring, hints, timed play and draw-three mode are not included.

Example

After installing, choose Game > New game to begin a fresh deal.
