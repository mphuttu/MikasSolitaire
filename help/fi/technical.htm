Tekniset tiedot

Kuvaus

MikasSolitaire on Windowsin MFC-sovellus. Direct2D piirtää kortit ja Windows Imaging Component purkaa ja skaalaa mukana tulevat PNG-kuvat.

Käyttö

Pidä MikasSolitaire.exe, MikasSolitaire.chm, MikasSolitaire-fi.chm sekä kansiot res\front ja res\back yhdessä. X64-asennuspaketti sisältää Microsoft Visual C++ -ajonaikaisympäristön.

Huomaa: .mksol-tiedosto sisältää nykyisen ja alkuperäisen jaon. Kortin tausta ja kieli tallennetaan nykyisen Windows-käyttäjän profiiliin.

Vinkki: Käännä ratkaisu Visual Studio 2026:lla ja C++:n MFC-komponenteilla. HTML Help Workshop kääntää molempien kielten ohjeprojektit.

Varoitus: Älä muokkaa binäärisiä tallennustiedostoja; virheelliset tai tuntemattomat tiedot hylätään.

Rajoitukset

Asennuspaketti on 64-bittiselle Windowsille. Windows voi estää verkosta tai Internetistä ladattujen CHM-tiedostojen näyttämisen.

Esimerkki

Siirrettävä julkaisu tarvitsee ohjelman, sopivan Visual C++ -ajonaikaisympäristön, 52 korttikuvaa, kuusi taustakuvaa ja molemmat ohjetiedostot.
