Customization

Description

Choose among six card-back designs and adjust the game window to suit your screen.

How to use

  1. Open Game > Card back.
  2. Select Back 1 through Back 6; the current choice is marked.
  3. Resize or maximize the window to change the displayed card size.

Choose Game > Language / Kieli to select English or Finnish. The application and help use the new language after the next application restart, and customized menus are reset. The installer language is selected separately.

Some Windows and MFC-provided dialogs may use the Windows language or English.

Note: The card-back choice is stored as a Windows user preference, not in the game file.

Tip: A larger window provides more room for card details.

Warning: If Windows cannot save the preference, the application reports the error and the choice may not persist.

Limitations

Only the six supplied backs are selectable in the application. Card faces and the table colour are not configurable.

Example

Select Back 3; face-down cards and the stock immediately use that design.
