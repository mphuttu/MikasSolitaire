Technical Information

Description

MikasSolitaire is a native Windows MFC application. Direct2D renders the cards, and Windows Imaging Component decodes and scales the supplied PNG images.

How to use

Keep MikasSolitaire.exe, MikasSolitaire.chm, MikasSolitaire-fi.chm, and the res\front and res\back directories together. The x64 installer includes the Microsoft Visual C++ runtime redistributable.

Note: Saved .mksol files include the current and original deal; the six-back preference is stored in the current user's Windows profile.

Tip: Build the solution with Visual Studio 2026 and the C++ MFC components. HTML Help Workshop compiles both help projects.

Warning: Avoid editing binary save files; invalid or unsupported data is rejected.

Limitations

The provided installer targets 64-bit Windows. HTML Help is a Windows component; CHM files may be blocked from network or Internet locations.

Example

A portable build needs the application, its matching Visual C++ runtime, 52 face images, six back images, and the compiled help file.
