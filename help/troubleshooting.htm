Troubleshooting

Description

Use the checks below when a move, saved game, image or help file does not work.

How to use

  • Card will not move: check rank, colour, suit, and whether it is exposed. An empty column needs a king; an empty foundation needs an ace.
  • Image cannot be loaded: ensure all supplied PNG files remain under res\front and res\back beside the application.
  • Saved game cannot be opened: check that it is a valid, complete .mksol file. Try another backup.
  • Help will not open: check that MikasSolitaire.chm is beside the executable and accessible. Windows may block CHM content downloaded from the Internet; inspect the file's Properties.
  • Application will not start: install or repair the matching Microsoft Visual C++ x64 runtime using the installer.

Note: The application reports file and rendering errors; do not ignore the displayed path or error code.

Tip: Save a backup under a different name before troubleshooting.

Warning: Do not overwrite your only saved game when investigating file errors.

Limitations

Damaged saved games cannot be repaired by the application.

Example

If a heart three will not move to a foundation, first ensure the heart two is on that foundation.
