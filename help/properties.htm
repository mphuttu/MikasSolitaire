Game Properties and Commands

Description

The following commands control the current deal and application appearance.

How to use

Command or propertyAction
Game > New game / Ctrl+NStart a new shuffled deal.
Game > Restart dealRestore the current deal's original layout after confirmation.
Game > Open / Ctrl+OOpen a saved .mksol game.
Game > Save / Ctrl+SSave the current position; choose a name on the first save.
Game > Save asSave the position under another name.
Game > Card backChoose one of six backs.
Help > Contents / F1Open this help file.
Right-clickCancel the selected card or sequence.

Note: A saved game contains both the current position and the original deal.

Tip: Use Save as to keep separate checkpoints.

Warning: Opening another game or starting a new one replaces the current position. Respond to the unsaved-changes prompt carefully.

Limitations

There is no scoring, timer, undo, draw-three mode or configurable number of stock passes.

Example

Save a position, try a move, then reopen the saved file to return to that position.
