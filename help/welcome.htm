Welcome to MikasSolitaire

Description

MikasSolitaire is a Windows Klondike solitaire game. Build four foundations from ace to king, one suit per foundation.

How to use

  1. Start the application and inspect the seven columns.
  2. Move cards by dragging, or by clicking a source and then a destination. Double-click an eligible top card to send it to a foundation.
  3. Click the stock at the upper left to draw.

Note: The stock is dealt one card at a time and may be recycled without a limit.

Tip: Select Help > Contents or press F1 to return to this help.

Warning: Starting a new game replaces the current deal; save it first if you want to return to it.

Limitations

The game uses one deck and does not guarantee that every shuffled deal is solvable.

Example

Double-click an exposed ace to place it on an empty foundation.
